The existing quality ceilings remain frozen: raw Euler and local orientation

0.00001; local translation min(0.0002, 0.0001 × L); native bone and skinned-vertex

component limits per frame. L is the finite positive original target bind-geometry
bounding-box diagonal. Without a valid scale reference, retain exact native data.
No hidden tolerance increase, bone/character/action/hash exceptions or new solver.

alone. Uncertain spans retain keys. Independently encode/reopen all curves and
metadata, then apply the existing cumulative native orientation/FK/skin and
derivative checks. Restore exact dense data when a bounded candidate fails these
