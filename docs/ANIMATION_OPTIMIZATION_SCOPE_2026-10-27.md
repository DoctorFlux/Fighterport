# Current-animation optimization — frozen implementation and verification scope

The user explicitly authorizes the standalone current-target-animation optimizer,
with Exact cleanup default and optional High-quality reduction, whole-clip scope,
reviewed removal of tracks absent from the target, Analyze/Apply/native Undo and
background-only verification. No automatic optimization at transfer, fitting,
Save or export. Preserve the full native previewer, original Next and root policy.

Deliver preview.45 Exact first, then preview.46 High-quality. Expose no unqualified
High-quality command in preview.45. Both remain inside the ONE incomplete G1/M2.

## Frozen math and native boundaries

- Native CHR0 v4/v5, integral source knots and precise I12 output. No new native
  codec or Melee writing claim. The unchanged original Next already creates
  target-only tracks; regression-test that invariant rather than rewriting it.
- Pure Core constrained Hermite span reduction, source knot times and retained
  endpoint values/tangents. Exact rational polynomial/Bernstein equality for Exact;
  conservative normalized Bernstein value/derivative bounds for High-quality.
  Uncertain or work-limited proofs retain keys. Paired sides, jumps, turns, sparse
  bind semantics, signed-zero distinctions, loop bridge and native flags survive.
- Missing-target tracks are explicitly listed before the user's Apply. Original
  source bytes, snapshots and metadata remain immutable. Native membership uses
  the frozen target, never role/name heuristics or mesh-weight eligibility.
- Root motion controls: exact-only curve cleanup, never approximation/reference
  substitution. Pins/contact dependency closures preserve native structures,
  including all ancestors and positive skin influences/support relationships.
  Unknown protection context is reported; no inferred contacts or role guesses.
- Whole-clip High-quality is authorized, including the attack middle. Fitting
  endpoints/joins and protected intervals/keys remain exact. Existing receipts
  remain historical; never replace initial bake/fit hashes with optimized hashes.

High-quality bounds fixed before implementation:

| Quantity | Bound |
| --- | --- |
| Raw Euler channels and local orientation | 0.01 degrees |
| Scale components | 0.00001 |
| Local translation | min(0.0002 native units, 0.0001 L) |
| World bone positions and all skinned vertices | 0.0001 L |
| Euler derivative | 0.05 degrees/native frame |
| Translation/scale derivative | corresponding component bound/native frame |

`L` is finite positive authentic bind-geometry bounds diagonal, frozen before
optimization. No guessed unit length. Exact remains available without `L`;
High-quality reports unavailable geometry. Zero/sign-changing scale spans are
exact-only, not normalized or rejected merely for mirroring.

Core continuous bounds concern mathematical scalar Hermite curves. Fresh native
float encoding/evaluation roundoff is measured independently at exact keys, both
pair sides, seams, extrema, withheld/native subframes and adaptive witnesses.
Native cumulative local/world/skin validation is required; Core scene evaluation
cannot replace native scale/compensation semantics. Sampled geometry is not a
continuous-time certificate. Existing .0002 translation, .00001 scale and .01-degree
orientation comparisons bound native rounding in Exact mode; no intentional error.

## Operation and verification

Independent frozen current clip/rig/content/protection inputs. No document changes
until one native Undoable Apply to the same object. Guard completion and Apply;
cancel/stale/failure leaves content, selection, bone, frame, camera, Undo and dirty
state unchanged. Save/export/reopen retain optimized native keys/flags and siblings.

Use existing key/pose/skin work budgets and cancellation; never reduce verification
density to force a pass. Count actual native I12 bytes and original stored bytes
separately when available. Reject growth; no savings is an honest unchanged result.
No PAC/PCS savings claim without actual container measurement. Session baselines
prevent repeated unchanged optimization from silently accumulating approximation;
reopen/manual edits establish a reported new baseline. No project schema changes.

Require original procedural Hermite oracles, nonzero equal-value overshoot, sparse
nonneutral bind fallback, pairs/jumps, 720-degree turns, loops, mirrored/zero scale,
unweighted helpers, target-absent tracks, native isotropic-scale tangent cases,
hierarchy-amplified errors and budgets/cancellation. Native private-desktop cases
cover ordinary clips, Next in both directions, fitting, ownership/siblings, native
Undo, Save/export/reopen, failures/staleness and compact/wide 100%/175% captures.
Inspect actual images. Physical input/DPI, broad contacts, additional adapters and
actual game acceptance remain unverified.

Primary design reference: [hierarchy-amplified compression error](https://nfrechette.github.io/2023/02/26/dominance_based_error_estimation/).
No ACL runtime format or external codec is introduced.

## Resource-policy correction before preview.45 qualification

The initial adapter prototype introduced lower work ceilings (80 million skin
visits / 32,768 witnesses) than the plan's existing operation budgets. They safely
refused the authentic 75-frame Snake raw replay without publishing a candidate.
Align the optimizer with the existing reconstruction resource policy: 100,000
logical witnesses, ten million bone visits and one billion skin visits, counting
both baseline/candidate evaluation. No sampling density, scalar/pose tolerance or
contact/floor gate changes. Shared counters will bound cumulative retries in the
later High-quality increment; exhaustion still leaves the document unchanged.

## Frozen preview.46 preparation policy

Verify an Exact candidate first, retaining it as a possible fallback. Then try
High-quality scalar bounds at 1, 1/2, 1/4 and 1/8 of the fixed ceilings, always
starting from the immutable session baseline. Native pose/mesh limits never grow.
Stop after the first completely verified High-quality candidate, choosing a smaller
verified Exact candidate if it saves more bytes. This bounded greedy search does
not promise a global minimum or monotonic geometry improvement across retries.

Share 2,000,000 Core proof work units and 100,000 candidate spans across attempts,
and share the existing native witness/bone/skin budgets. Retry only identified
quality or size rejection. Work exhaustion stops preparation and offers only a
previously complete verified candidate or unchanged content. Cancellation, stale
dependencies, encoding/metadata/ownership failures discard the operation. Reports
identify each rejected attempt, chosen mode, baseline hash and aggregate work.

Session retention is per exact clip/target, including A → B → A navigation.
Bound aggregate retained snapshots by the existing two-million-key / 256 MiB
operation ceilings, with LRU disposal of snapshot payloads. Keep a compact exact
identity/hash marker when a payload is evicted. Such a marker may replay the
unchanged result but cannot silently authorize another approximation: unavailable
original baselines block new HQ preparation. Exact cleanup remains available;
manual authored edits or reopen establish an explicitly identified new baseline.
Prepare the cache-owned baseline before changing the live clip, so an allocation
or snapshot failure cannot leave a successful edit presented as failed Apply.

## Native metadata qualification boundary

The existing reader/writer does not represent nonzero CHR0 scaling rules or
arbitrary opaque v5 user data. Reject those inputs before snapshot/content hashing
instead of silently replacing metadata. Check both original and working raw
buffers, because a prior native rebuild can already canonicalize working bytes.
Qualify v4/v5 with scaling rule zero, canonical loop integers, supported original
path layout, and canonical known Int/Float/single-String user data with unique
UTF-8 names, ordinal IDs and exact finite native float roundtrips. Unsupported or
malformed metadata leaves the animation unchanged with an explicit explanation.
This is a narrow qualification guard, not a new writer/evaluation adapter.
