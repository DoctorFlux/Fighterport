## Existing-track fitting

Default full fitting remains unchanged. An explicit bone-level option freezes
membership from current target CHR0 tracks having at least one authored key and an
exact target bone match. It does not infer animation membership from bone names,
mesh weights or bind pose. Existing selected S/R/T components may be authored on
those bones; new bone tracks are forbidden. Reference controls and contact/recovery
dependencies cannot silently broaden the set. Explain omitted optional controls;
name and block incompatible mandatory dependencies. Additive false-default recipe
fields preserve old reads without project-format migration.

## Source-key retargeting

Original dense Next remains the default. Add two explicit alternatives:

- Source bone keys: keep the mapped source bone's union of authored key times
  while allowing the target's necessary axes to differ for its authentic binds.
- Source channel keys: retain individual mapped source-channel times/counts and
  absent channels. This stricter representation can lose necessary cross-axis
  compensation on unequal rigs.

Both contain retargeted target-space values, never a blind source-value copy.
Filter target-absent bones; preserve paired sides, timing, loop and full turns.
Reviewed motion controls retain their exact existing own-source local-curve
policy. Independently measure sparse motion against frozen dense Next and expose
losses for review before authoring a target revision. Source-key equality is not
an identical-pose guarantee. Old dense contact/quality evidence cannot be relabelled
as sparse validation. Record the chosen representation in additive recipe evidence.

## Compact native storage

The user's additional constant/bind cleanup rule is included here: a proven
constant channel becomes one native first-frame key, including shifted constant
knots. When all authored channels stay exactly at the actual target's raw native
bind values, remove that animation track after review. Never remove model bones.
Check Hermite interiors, raw Euler turns, signed zero, paired sides, mandatory
fitting joins, pin/contact structures and native scale-compensation flags before
allowing this cleanup. Equal keyed values alone do not prove constant motion.

Keep ordinary precise I12 behavior available. Explicit indexed I4/I6 choices may
reduce bytes further; do not invoke the legacy automatic selector, Clean, L1/L4
resampling or arbitrary decimation. Preserve supported canonical metadata, track
membership/order, sparse channels, paired sides and native time semantics.

Exact mode permits packed storage only when independent decode preserves every
required coefficient bit (including signed zero). High-quality packed coefficients
must pass continuous rational Hermite value/derivative certificates against the
retained original session baseline AND complete independent native local/FK/skin
validation. Keep preview.46's frozen ceilings unchanged: raw Euler/orientation
0.01 degrees; scale1e-5; translation min(.0002,1e-4L); world/skin1e-4L; Euler
speed .05 degrees/frame and corresponding T/scale component bounds/frame.

Protected roots, fitting endpoints/joins, pins/contact dependency closure and
singular/sign-changing scale stay exact-only. Changing an encoded track later
invalidates its packed plan and falls back to precise storage, never unchecked
automatic requantization. Save, verified export, Undo/Redo and reopen must retain
qualified storage; source originals and historical receipts remain immutable.
Use aggregate existing work/key/pose/skin budgets, cancellation and stale guards.
Choose actual measured bytes with a verified precise fallback, never a larger or
incompletely checked result. Report standalone/resource/container sizes separately.
