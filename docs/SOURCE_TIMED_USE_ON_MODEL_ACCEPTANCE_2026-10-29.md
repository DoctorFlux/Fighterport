## Change and scope

The ordinary library/source **Use on This Model** button now starts fresh UI
sessions with **Source channel keys**, rather than Dense. Existing explicit
Dense, source-bone and Interpolated choices remain available through
**Animation → Retarget options…**. This menu works with a target model before an
animation has been imported. The button's tooltip/accessibility and existing
source details identify the selected policy. Original Next still produces the
full-quality reference; its enum/API/legacy-provenance Dense default is unchanged.

The second defect was an entire-channel paired-key guard: a single generated
pair could retain every original target row even between sparse source knots.
Exact evidence for writer-generated continuous pairs now permits time-group
reduction. Retained pairs keep both ordered sides; removed pairs require
continuous native Hermite value/derivative certificates over adjacent original
intervals. Unknown/authored pairs and signed-zero channels retain the previous
whole-channel protection. Frozen rig/context/ordered bits, exact controls,
singular/sign-changing scale, mandatory/protected/contact/fit joins and final
native cumulative checks remain binding. See
[implementation notes](SOURCE_TIMED_USE_ON_MODEL_NOTES_2026-10-29.md).

Source times are seeds, not permission to discard necessary target motion.
Derived target axes or extra repair keys can remain where axis conversion,
proportions or original Next corrections need them. This does not promise a
source-identical knot list for every unequal rig. No character/action-specific
production exceptions, tolerance relaxation, new editor, project schema,
solver, renderer or playback processing is introduced.

## Frozen quality and ownership

Retarget ceilings remain 0.01° raw Euler/local orientation, 0.00001 scale,
min(0.0002 native units, 0.0001 × L) local translation and 0.0001 × L native
world/basis/skin distance. Derivatives remain 0.05° per frame for Euler and the
corresponding component limits per frame. `L` is the original target's finite
positive bind-geometry diagonal. The existing 2M scalar-work, 100k span and shared
100k native sample / 10M bone-visit / 1B vertex-visit budgets remain unchanged.
No search or loading is added to playback.

The four grouped proposals share one frozen finished target and all budgets.
If they fail, the existing fifth slot may try the previous conservative paired-
preserving representation under the same strict gates; otherwise exact Dense is
retained. No failed approximation is published. This avoids unnecessary storage
regression without weakening a failed motion check.

Native preparation serializes and freshly decodes the actual candidate before
complete metadata/key/tangent/flag and cumulative model checks. Rational scalar
bounds and finite native geometry/derivative witnesses remain distinct evidence.
Full native previewer, reviewed mappings, source-local protected roots, model
hierarchy/rest/inverse binds/all skin coefficients, source hashes, native Undo
and ordinary exact project Save remain intact.
