## Behavior and storage boundary

Animation → Optimize animation… continues to operate on the exact owned animation
selected in the target Model Previewer. Exact remains the default; **Smaller native
storage** is an explicit option. High quality remains separately selected. Nothing
runs automatically during retargeting, fitting, playback, Save or export. The
complete native editor, original Next, existing rigs and native Undo remain.

The option considers explicit indexed I4/I6 storage for complete native SRT groups,
with precise I12 fallback. Knot times/order, paired sides, track order and native
semantic flags remain. The legacy automatic codec selector, dense L1/L4 codecs,
Clean, tangent regeneration, shortest-path quaternion curves and periodic
decimation are not used to qualify storage. A proposal's estimated payload size is
not reported as its final saving: complete fresh CHR0 files and their declared
resource blocks are measured independently after encoding and reopening.

An immutable packed payload is usable only while its decoded knot indices, values
and tangents match the current authoring data bit for bit. A subsequent edit falls
the affected group back to precise storage; it does not silently requantize the
edit. Effective storage identity is frozen alongside semantic content, target,
ownership, controls and historical recipe evidence. Native snapshots preserve
storage for Undo/Redo, project Save, verified single/set export and reopen.
Historical retarget/fitting result hashes remain historical evidence.

Exact packing requires independently decoded complete coefficient/metadata
identity. When only representation changes, that identity carries the already
qualified precise curve proof without spending another full solver or geometry
budget. It is not a claim that separate codecs execute bit-identically in a game
at every possible time. Reports explicitly distinguish carried proof from newly
sampled native geometry work.

High-quality packing keeps preview.46's frozen bounds: Euler/local orientation
0.01 degrees; scale components 0.00001; local translation
min(0.0002, 0.0001 × L); native hierarchy/skin 0.0001 × L; Euler derivative
0.05 degrees per frame; translation/scale derivatives use their corresponding
component limits per frame. L comes from the target's authentic bind geometry.
Decoded cumulative candidates are compared to the retained original session
baseline using rational Hermite/Bernstein scalar value/derivative certificates,
then independent native local/FK/skin evaluation. These are different claims:
continuous scalar bounds do not establish continuous geometry/contact quality.

Source-owned motion controls, fitting endpoints/joins, paired sides, signed zero,
authored pin/contact dependency closures and singular/sign-changing scales retain
their required exact protections. Missing context is reported. Negative and
nonuniform scale are not normalized. Both source/candidate inputs and shared
work/span/native witness/bone/skin counters stay within the existing operation
limits. Budget exhaustion returns only a previously verified fallback or unchanged
content. Cancellation and stale/fatal failures publish no candidate.

Packing first tries a lossless batch, then bounded complete quantized batches
(smaller indexed choices, followed by available I6 alternatives). A rejected batch
retains the qualified lossless/precise fallback and says so. This conservative
bounded search is not a globally minimal file-size algorithm. Final standalone
and resource-block sizes cannot exceed either current measured storage or
applicable clean original-input caps. PAC/PCS alignment/compression savings need
separate actual measurement.

## Constant and bind cleanup

A proved constant channel becomes one native frame-zero key. Equal values with
nonzero Hermite tangents are not treated as constant. Signed-zero and paired-side
data remain protected. A live single zero-slope key at a later frame is normalized
only on an independent storage-verification copy; the live raw timing remains
available to Undo until the explicit optimization applies.

Removing a bind-equivalent animation track requires original raw native bind
values, exact constant curves, no incompatible structural/fit protections, and
matching native scale-compensation semantics. It removes an animation entry,
never a model bone. Eligibility is established from the original input, so an HQ
approximation approaching bind pose cannot turn into an allegedly exact bind
omission. The independent adapter rechecks eligibility and complete native
hierarchy/skin behavior rather than trusting the Core omission list.

## Independent review and development findings

- Core bind cleanup was corrected to check the original raw input rather than a
  post-HQ constant result. Protected absent-target omissions now reject directly
  in the generic scalar certificate; individual input key limits are enforced.
- Single shifted fixed keys needed an independent canonical storage-verification
  copy. Native source content and Undo continue to identify the original raw knot.
- An early codec fixture omitted two axes of a present native SRT group. Native
  reopen correctly materialized fixed axes. The fixture was corrected to use
  canonical group membership; coefficient/error checks were not weakened.
- A workspace assertion incorrectly counted the entire Undo list after Undo left
  a redo branch. The corrected test checks the applied cursor, branch truncation,
  exact original baseline, successful dialog Apply and actual one-step Undo/Redo.
  Diagnostics confirm content/storage/baseline matches, cursor 1 → 2 and list
  count 2 → 2, as expected for replacing that undone branch.
- Review found that a precise node with an explicitly cleared policy could
  accidentally re-adopt matching packed bytes left in its working buffer after
  Save. The explicit precise policy, including null, is now authoritative; raw
  payload parsing is reserved for ordinary native nodes. New final-build tests
  cover Save/rebuild → Undo → precise export → Redo.
- Storage-only unpacking must not establish a new HQ quality baseline. Original
  baseline validity now follows semantic content, rig and protections; storage
  identity remains part of stale-operation checks and same-result cache reuse.
  A new final-build fixture unpacks an unchanged HQ result and requires reanalysis
  against the retained original, reproducing the same bounded candidate.
- Native curve-editor references now clear safely when reviewed cleanup removes
  their animation entry. The broad workflow checks Apply, native Undo/Redo and
  exact target/bone/frame ownership through this previously failing path.
- Root cleanup is checked against an independent frozen original: retained flags,
  both paired sides, raw Euler winding and native fractional functions. An omitted
  root additionally needs bit-exact bind constants, positive-zero tangents and
  matching model scale flags. Raw track hashes alone cannot distinguish legitimate
  exact cleanup from a motion change.
- Protected ranges and mandatory points inside sparse spans require exact
  polynomial identity, even when the protected interval contains no authored
  knot. A reproduced 1/1024-degree shift was within ordinary HQ bounds but
  correctly fails the protected-span certificate. Authored joins retain their
  exact tuples without forbidding bounded changes in adjacent unprotected spans.
- Positive or negative source scale cannot acquire a new zero/sign crossing
  merely because its absolute error is small. A reproduced positive 2^-20 scale
  example crossed zero after a three-to-two-key merge. Candidate span hulls now
  need a proved sign, and certificate exact-only classification considers both
  original and decoded scale curves. Existing singular curves retain Exact
  cleanup; negative/nonuniform scale is not normalized.
- The independent procedural packing inequality uses the actual native
  Keyframes.FrameLimit for wrap spans. Native decode, scalar and geometry
  thresholds were not relaxed while correcting this test observer.
