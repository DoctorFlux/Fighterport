## Budget diagnosis and correction

The previous refinement compared native interpolation with independent redundant-
joint IK optima at every subframe. That generated a noisy reference and repeatedly
regenerated tangents. The new offline path freezes original-fidelity integer poses
and retained tangents, then projects failing samples of the actual native curve onto
the same hard contacts. The earlier reviewed approach adds a smooth cubic correction
while retaining original native key times, values plus correction, tangents and paired
sides. It does not repeatedly solve unrelated subframe body optima.

The strict solver still has its original objective, 48 iterations and internal
failure bounds. Optional warm starts preserve already feasible seeds. Double-
precision normalized angle measurement removes false float quaternion norm error;
a genuine 0.002-radian contradiction still fails the unchanged 0.001-radian gate.

An optional observer copies an **unvalidated failed iterate** without changing its
failure result. Reviewed authoring can independently qualify it against the existing
public contact contract. When needed, an analytic translation interval intersects
contact-point and sole error spheres with complete-foot floor inequalities along
the reviewed floor normal. Its effect uses every original skin coefficient and a
reviewed body ancestor, never root compensation or reweighting. The entire pose is
rechecked. Strict solver failure and independent authoring acceptance are reported
separately. Fresh native serialization/reopen remains mandatory.

Limits remain 30,000 offline pose evaluations, 240 edited native samples, 64 contact
ranges and two million keys/full-skin verification work. No work occurs on playback
ticks. Cancellation and budget exhaustion publish no partial candidate.
The receipt counts sampled pose/solve requests and curve checks; it does not count
each internal solver Jacobian/FK evaluation as a separate request.
