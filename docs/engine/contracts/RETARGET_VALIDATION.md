## Native precision defect found by broader fixtures

Five preliminary native transfers failed independent reopening even though displayed/editor keys appeared valid. A finite float can have a byte-reversed signaling-NaN bit pattern. The pinned x86 BrawlLib `bfloat` implementation swaps through a float intermediate; quieting that NaN changed ordinary native values. Examples: −27.947996 decoded/wrote as −27.979246, and −63.656246 as −63.718746. JSON serialization was independently ruled out.

The owned worker now reads fixed/I4/I6/I12/L1/L2/L4 CHR0 float payloads with bounded integer endian operations before native sampling. Derived float fixed/I12 writes overwrite affected payload fields after header encoding. Exact key/tangent checks run before and after fresh native decode; standalone CHR0 output is staged and committed only after verification. Original bytes remain untouched. Reader provider is `native.brawl.v2.integer-floats`; v1 library caches must be re-registered from preserved originals. Existing component/license/revision/dependencies/notices remain in `LICENSE_AUDIT.md`; no new parser/editor shell was copied.
