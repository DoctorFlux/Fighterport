## Shared behavior

The existing native **Fit start or end** workflow adds an explicit **Prevent extra
foot dipping during exit recovery** option and reviewed native Y support plane.
It uses the exact reviewed body/leg bindings, authentic inverse binds and every
vertex with any positive reviewed ankle/descendant influence. Original skin
weights, skeleton and source bytes remain unchanged. No character, action, bone
name, asset hash or storage-index numerical exceptions are introduced.

The reference contributes only its authentic frozen first BODY pose. Protected
motion controls retain their own source-authored local curves at every time;
reference controls never reset or align them. `contact-exit-recovery-2` records
this separation. Historical `contact-exit-recovery-1` recipes remain readable.
The original Next retargeter and complete BrawlCrate Model Previewer remain intact.

Clearance uses the explicit per-foot baseline
`min(0, original motion(t), authentic reference body under source roots(t))`.
It prevents added penetration; it preserves authored source/reference penetration.
This distinction is necessary because authentic Mario Wait1 frame 1 already
slightly crosses the native Y=0 guide. Root travel cannot be removed to hide it.
The final attack frame reaches Wait1's first body pose under the attack's own
root placement, then the GIF holds only that reference frame.

A conservative piecewise Hermite envelope rises during the first recovery
interval, holds its normal displacement at interior integer knots and returns
during the final interval. Its scalar amplitude is solved from actual baked
responses, then independently measured. It is not a minimum-lift or planted-foot
solver. Correction is confined to the reviewed body translation after the original join.
Native keys stay integral. Prefix keys/tangents, protected roots, reference bytes,
frame count, timing and loop state remain exact. Hard/soft editor pins, authored
contact anchors and overlapping protected intervals reject conflicting recovery.
The operation prepares an independent candidate, requires result review and uses
one existing native import/Undo transaction. Playback performs no recovery work.

## Frozen gates and scope

Before implementation the sole current plan froze maximum added penetration at
0.0002 native units, endpoint/prefix translation at 0.0002, scale at 0.00001 and
orientation at 0.01 degrees. The correction has at most 8192 new hip keys and
200000 pose evaluations; maximum lift is 20% of the shorter reviewed leg-chain
length. All vertices are retained; excessive work rejects instead of sampling a
smaller geometry set. Independent checks use 1/64-frame samples and held-out
fractional witnesses. This is sampled clearance, not a continuous-time proof.

Current support is explicitly reviewed static-plane, non-looping, exit-only,
full-S/R/T recovery to a frozen first reference body pose. Missing geometry,
unreviewed or singular placement, conflicting constraints, excessive lift and
nonconvergence reject without publishing a result. Contact locking, foot sliding,
velocity/acceleration quality, moving supports, arbitrary anatomy and stored-loop
recovery need their own acceptance. A shared algorithm is not evidence that every
character and animation has passed those gates.
